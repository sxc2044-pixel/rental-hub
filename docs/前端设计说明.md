# 校园安居前端设计说明

服务对象是需要在校园附近租房的学生，以及处理房源审核与预约的管理员。页面的主要任务是帮助学生比较房源、确认配置和预约看房。

## 设计基线

| 色彩令牌 | 色值 | 用途 |
| --- | --- | --- |
| 雾白 | #F5F7FA | 应用背景 |
| 纯白 | #FFFFFF | 内容表面 |
| 深蓝灰 | #203448 | 主文字与品牌 |
| 青绿 | #167D8D | 主要操作、导航当前状态 |
| 石板灰 | #687787 | 次级文字 |
| 浅蓝灰 | #E3E9EF | 分隔、边框和未选状态 |

中文优先使用Microsoft YaHei与PingFang SC，同一家族通过字号和字重建立层级。正文15px、辅助说明12至13px、区块标题20px、页面标题28至34px。长段落控制在约60个中文字符宽度。内容左对齐，价格与数值保持清晰可比较。

## 布局方案和审查

初稿考虑延续插画横幅；对照本次“专业、清晰、留白”和真实照片的要求后，移除插画及装饰英文。视觉重点集中在房源照片，搜索始终在首屏。卡片只用于房源这种需要重复比较的对象，普通说明使用开放区块与细分隔线，不把所有信息包装成相同卡片。

```text
桌面首页
┌─────────┬──────────────────────────────────┐
│ 品牌导航│ 页面位置                 个人入口 │

详情页
返回与房源编号
┌─────────────────────┬─────────────────────┐
│ 大幅房源照片         │ 标题、价格、面积、户型 │

├─────────────────────┴─────────────────────┤

│ 房源介绍、看房须知、公开评价               │

```

手机使用顶部品牌与可滚动导航，房源单列、详情上下排列、设施网格自适应。交互保留可见焦点、禁用、加载、选中和错误状态；不依赖颜色单独表达是否配备，尊重减少动态效果偏好。

房源与新学生是明确的示例数据。网络照片依许可本地保存，来源记录在图片来源与使用说明.md；不得把配图标成对应示例地址的真实房屋照片。新增学生账号从2023100514开始，既有账号与业务记录保留。
